## 🌍 About the Project

**TripTastic** is an AI-powered travel planning web application built to make trip planning simpler, more interactive, and personalized. Instead of manually researching destinations, dates, group preferences, activities, budgets, and travel information across multiple websites, users can organize their trip through a guided planning experience. TripTastic uses **Google Gemini** to generate personalized itineraries and combines travel information such as destinations, places, maps, weather, currency conversion, and destination imagery into one experience. It is designed for travelers, groups, and anyone who wants a visually engaging way to plan a trip.

## ✨ Key Features

- 🤖 **AI Itinerary Generation** — Generate personalized travel itineraries using Google Gemini.
- 🧭 **Interactive Trip Planner** — Plan a trip through a guided multi-step wizard.
- 📍 **Destination Discovery** — Search and explore available travel destinations.
- 🗺️ **Interactive Maps** — Visualize destinations and itinerary locations using Leaflet.
- 🌦️ **Weather Information** — Retrieve weather information for destinations.
- 💱 **Currency Conversion** — View exchange rates and convert between currencies.
- 🏞️ **Places Discovery** — Discover tourist attractions and places around destinations.
- 🧑‍🤝‍🧑 **Group Planning** — Enter travelers, group size, preferences, and budget information.
- 💰 **Budget Overview** — View trip budget and cost distribution.
- 💬 **AI Travel Assistant** — Chat with AI about the generated itinerary.
- 🖼️ **Destination Images** — Retrieve destination imagery with Pexels support and curated fallbacks.
- ✈️ **Flight Integration Structure** — Backend routes are prepared for flight-related integrations.
- 🏨 **Hotel Integration Structure** — Backend routes are prepared for hotel-related integrations.
- 🌗 **Theme Support** — Light/dark visual theme support.
- 🎞️ **Animated UI** — Framer Motion, GSAP, and Lenis provide interactive transitions and smooth scrolling.
- 📱 **Responsive Design** — Designed to work across desktop and mobile screen sizes.
